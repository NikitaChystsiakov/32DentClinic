Дата: 14.09.2026. Аудит внутренний — по коду и контенту репозитория, без

1. **Имплантация заявлена главной услугой, но на сайте её почти нет.**
   На всю сеть — одна страница `/uslugi/implantaciya/` с двумя строками

2. **В Минске — главном городе по имплантации — нет ни одного реального
   врача, и нет имплантолога даже среди заглушек.** Три карточки-заглушки:
   два терапевта и ортопед. Единственный имплантолог сети (Махонько) числится

   Жлобина; в Жлобине имплантация есть в SEO-описании, но нет в списке услуг
   города.
4. **На боевых страницах Минска и Жлобина видны технические заглушки:**
   в карусели отзывов рендерится «TODO: добавить отзыв», в блоке рейтингов —

5. **Контента, который приводит трафик, нет:** блог пустой (один шаблон),

   пришёл по бренду.

Из этого примерно 60 % закрывается самостоятельно (структура, тексты-черновики,
FAQ, статьи), 40 % — только с данными клиники (врачи, цены, бренды имплантов,
фото, реальные отзывы).

### 1.2. Почему одной страницы «Имплантация» недостаточно

Пациент, который решает про импланты, проходит 3–6 месяцев от первой мысли до
операции и за это время задаёт десятки конкретных вопросов: «сколько стоит
под ключ», «какой имплант ставите», «что если кости мало», «можно ли за один
день», «сколько живёт All-on-4». Сейчас сайт отвечает только на «есть ли у вас
имплантация» — да, от 700 р. Всё остальное пациент уйдёт искать у конкурентов,
и там же запишется.

С точки зрения поиска: одна страница может ранжироваться по одной группе
запросов. «Имплантация зубов минск», «all-on-4 минск цена», «одномоментная
имплантация», «синус-лифтинг цена» — четыре разных группы, нужны четыре
страницы.

### 1.3. Целевая структура раздела «Имплантация»

Раздел-кластер вместо одной страницы, в каждом городе (`/<город>/implantaciya/…`
или внутри `/uslugi/implantaciya/…` — решить при внедрении):

```
Имплантация (хаб-страница направления)
├── Одиночный имплант под ключ          — самый частый запрос, цена «под ключ»
├── Имплантация при отсутствии нескольких зубов (мост на имплантах)
├── All-on-4                            — своя страница: цена, этапы, срок, для кого
├── All-on-6                            — своя страница
├── Одномоментная имплантация (удаление + имплант за один визит)
├── Костная пластика и синус-лифтинг    — снимает главное возражение «у меня нет кости»
├── Протезирование на имплантах         — коронки, условно-съёмные, балочные
└── Цены на имплантацию                 — сводная таблица + «что входит в „под ключ“»
```

Каждая подстраница по одному шаблону: заголовок с городом → для кого / когда
показано → что входит в цену (таблица) → этапы и сроки → врач → кейс «до/после»
→ гарантия → FAQ (5–8 вопросов) → CTA «Консультация имплантолога».

Минимум для старта (P0): хаб + Одиночный имплант + All-on-4 + All-on-6 +
Костная пластика. Остальное — P1.

### 1.4. Главная страница города — как перестроить порядок блоков

Сейчас порядок: hero → «Что мы лечим» (7 равноправных карточек) →
калькулятор → врачи → этапы → кейсы → почему мы → галерея → отзывы →
рейтинги → FAQ → контакты. Имплантация тут — просто первая карточка среди
семи.

Предлагаемый порядок (Минск — обязательно, регионы — с адаптацией):

1. **Hero** — оставить, но заголовок про имплантацию, а не «Стоматология 32Дент+
   в Минске» (это для title, не для H1). Пример: «Имплантация зубов в Минске:
   от одного импланта до All-on-4 за 3 дня» — цифру подтвердить у клиники.
2. **Виды имплантации** — новый блок, 4–6 карточек с ценой «от» и ссылкой на
   подстраницу. Это ответ на «а что у вас есть» для тех, кто пришёл именно за
   имплантами.
3. **Сколько стоит имплант под ключ** — новый блок: 3 пакета (одиночный /
   All-on-4 / All-on-6) с прозрачной раскладкой «что входит». Это самый
   конверсионный блок для имплантации, важнее калькулятора.
4. **Врач-имплантолог** — персональный блок: фото, стаж, число установленных
   имплантов, сертификаты, система имплантов. Не карусель «все врачи».
5. **Этапы** (есть, `treatmentTimeline` уже про импланты — хорошо).
6. **Кейсы до/после** — только имплантация, 3 штуки.
7. **Гарантия** — вынести тройную гарантию в отдельный визуальный блок, сейчас
   она размазана по hero, whyUs и FAQ.
8. **Остальные услуги** — компактная сетка «Также лечим: терапия, гигиена,
   протезирование…» — одна строка карточек, без описаний.
9. Отзывы → рейтинги → FAQ (в FAQ — 3–4 вопроса именно про импланты) →
   контакты.

Калькулятор уходит ниже или встраивается в блок 3 как «рассчитать свой
случай».

### 1.5. Хаб сети (`/`)

- H1 «Одна стоматология — три города» — про сеть, не про пациента. Заменить
  на обещание: «Имплантация и лечение зубов в Минске, Рогачёве и Жлобине».
- Блок NETWORK_PROMISES: «Собственная зуботехническая лаборатория» —
  **неправда для Минска** (там «Белая лаборатория»-партнёр). Переформулировать
  в «Зуботехническая лаборатория: своя в Рогачёве, сертифицированный партнёр
  в Минске» или убрать из общесетевых обещаний.
- В карточках городов бейдж «Имплантация» уже есть (`FEATURED_SERVICE_SLUG`) —
  хорошо. Добавить цену «от» рядом с бейджем.

### 1.6. Навигация и точки входа

- В меню нет пункта «Имплантация». Добавить первым, до «Услуги».
- В калькуляторе «Импланты» — один из вариантов среди прочих; сделать
  сценарий «Имплантация» первым и раскрыть его на подварианты (1 зуб /
  несколько / вся челюсть).
- Форма записи: добавить поле/чип «Меня интересует имплантация» — это
  сразу маршрутизирует лид к имплантологу и повышает ценность заявки.
- Промо-полоса в шапке Минска ведёт на общую страницу имплантации; после
  создания кластера — на страницу «Бесплатная консультация имплантолога»
  или на All-on-4.

  КТ, анестезия, хирургический шаблон, временная коронка — по каждому

  каждому — самый частый вопрос пациента.

- Сравнение «имплант vs мост vs съёмный протез» — таблица, хорошо работает
  на этапе выбора.

  имплантологии, система имплантов, с которой работает, видео-приветствие
