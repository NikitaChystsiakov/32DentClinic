## 1. Юридика (РБ)

### 1.1. Сайт — информация или реклама? Это определяет всё остальное

Позиция МАРТ: **обязательная информация об услугах на собственном сайте
(наименования, потребительские свойства, цена, условия) — не реклама**;
реклама — это акции и «прочие рекламные мероприятия»
([разъяснение МАРТ о рекламе на интернет-ресурсах](https://mart.gov.by/activity/regulirovanie-reklamnoy-deyatelnosti/o-sbore-za-razmeshchenie-rasprostranenie-reklamy/o-reklame-v-seti-internet/na-informatsionnykh-resursakh-v-seti-interne/)).

Если же контент — реклама медицинских услуг, включается **ст. 15 Закона
«О рекламе» № 225-З** (в ред. с 12.07.2024): согласование с Минздравом
(с исключениями), запрет ссылок на конкретные случаи излечения / улучшения
здоровья и благодарностей физлиц, запрет гарантий эффекта, обязательные
предупреждения и пометка «Реклама», УНП и наименование рекламодателя.
Требования в изложении 103.by: [info.103.by/legal_requirements](https://info.103.by/legal_requirements)
— там же прямо перечислен запрет приёма «До/После».

Сейчас сайт **сам расписывается в том, что он реклама**, и содержит рекламные
механики:

### 1.2. Отзывы — убрать

Вердикт: **блок отзывов убрать целиком**, пока нет реальных отзывов с
письменными согласиями. Причины:

1. **Рогачёвские отзывы выдуманы** (`content/rogachev.ts:310-346`:
   «Ольга, Рогачёв», «Андрей», «Пациентка»). Это недостоверная информация о
   услуге (ст. 7 Закона «О защите прав потребителей», ст. 10 Закона
   «О рекламе» — недостоверная реклама, гл. 3 Закона «О противодействии
   монополистической деятельности» — введение в заблуждение). Репутационный
   риск при проверке или жалобе конкурента выше любой пользы.
2. В Минске и Жлобине рендерится **«TODO: добавить отзыв»** с пятью звёздами.
3. Даже реальные отзывы в рекламном контексте — под запретом ст. 15
   (благодарности, случаи улучшения здоровья). «Коронку подогнали идеально с
   первого раза», «быстро помогли, когда заболел зуб» — ровно это.
4. Реальный отзыв с именем — персональные данные + **врачебная тайна**
   (сам факт обращения, ст. 46 Закона «О здравоохранении») → письменное
   согласие пациента на публикацию.
5. Кнопки «Оставить отзыв» и «Читать все отзывы на 103.by» — `href="#"`
   (`components/home/reviews-section.tsx:112-125`).

Что вместо этого — оставить `RatingsSection`, но с **реальными данными по
каждому городу** (`lib/data/aggregators.ts` сейчас рогачёвский, Яндекс и
Google помечены TODO). Карточка «4.9 на 103.by → смотреть отзывы» — это факт
и ссылка, а не благодарность. «Оставить отзыв» → прямая ссылка на форму
отзыва на 103.by/Яндекс/Google. Если клиника настаивает на цитатах на сайте:
только реальные, со скриншотом-источником и согласием, **о сервисе**
(запись, ожидание, объяснили план), без слов про лечение и результат.

## 4. Скорость

### 4.1. Первый экран невидим до гидрации (главное)

`components/reveal.tsx` — `motion.div` с `initial="hidden"` → на сервере
рендерится `style="opacity:0;transform:translateY(40px) scale(0.98)"`.
В `out/minsk/index.html` таких обёрток 32, **первая — вокруг hero с H1 и
LCP-картинкой** (`app/[city]/page.tsx:62`). Пока не загрузятся и не выполнятся
~1,1 МБ JS (≈340 КБ gzip), страница пустая; без JS — пустая навсегда. Это
напрямую бьёт по LCP/FCP в PageSpeed и по восприятию на мобильном интернете.

Что сделать:

1. Hero (и всё до первого экрана) — без `Reveal`, либо `initial={false}` для
   первых блоков.
2. Для остальных секций заменить `motion` на CSS: класс `.reveal` с
   `opacity:0; transform:…` только при наличии `html.js`, переключение
   `IntersectionObserver`-ом (≈30 строк), `@media (prefers-reduced-motion)`
   — без анимации. Это уберёт `motion` из критического пути.
3. Если `motion` остаётся — обернуть в `<MotionConfig reducedMotion="user">`.

### 4.2. Объём JavaScript

Главная Минска грузит 20 чанков, 1 097 КБ raw / ≈338 КБ gzip (без
`nomodule`-полифилла 109 КБ, который современные браузеры не качают).
Для статического сайта клиники ориентир — ≤ 150 КБ gzip. Откуда вес:

- `motion` (Reveal, hero, `treatment-steps.tsx` — 660 строк с анимированными
  частицами, `particle-field.tsx` на canvas);
- `embla-carousel` (врачи, отзывы, галерея);
- `@base-ui/react` (диалог, селекты, аккордеон);
- все секции главной — `'use client'`, хотя `WhyUsSection`, `FaqSection`,
  `GuaranteeSection`, `ServicesOverview`, `TreatmentSteps` — чистый контент.

Шаги: секции без интерактива перевести в серверные компоненты (читать
контент через `getCityContent(params.city)` на сервере, а не через
`useCity()`); карусели и `ParticleField` — через `next/dynamic` с
`ssr: false` только для интерактивной части; `Reveal` — на CSS (§ 4.1).

### 4.3. Весь контент города в каждой странице

`CityProvider` получает `content` целиком и, как клиентский контекст,
сериализует его в RSC-payload каждой страницы: на `/minsk/` это 57 КБ из
322 КБ HTML — все разделы, FAQ, отзывы, таймлайн, брифы фото, даже на
`/minsk/kontakty/`, где нужны только часы. Передавать в контекст только то,
что действительно читают клиентские компоненты (телефон, адрес, часы, promo),
остальное — пропсами из серверных страниц.

### 4.4. Картинки и медиа

- `loading="eager"` на всех фото в карусели врачей
  (`doctors-carousel-section.tsx:63`) → в `<head>` пять `<link rel=preload>`
  на портреты **ниже первого экрана**, которые конкурируют с hero-картинкой
  `/girlMain.webp` (175 КБ). Убрать `eager`; hero-картинке дать
  `fetchPriority="high"`.
- Картинки уже сжаты (webp, 20–60 КБ, 1600×1200) ✓. Из-за
  `images.unoptimized` нет `srcset` — телефон качает 1600px. Если захочется
  выжать ещё: `scripts/optimize-images.mjs` может писать варианты `-800w`, а
  компонентам отдавать `<picture>`/кастомный `loader` с готовыми файлами.
- Видео 27,7 МБ (Жлобин) и 20,8 МБ (Минск) — грузятся по клику ✓, но битрейт
  ≈2,6 Мбит/с для 720p избыточен: пережать до ~1,2–1,5 Мбит/с (≈10–12 МБ),

### 4.5. Хостинг (`public/.htaccess`)

Есть: 404, deflate, кеш `/_next/static/` и `/video/`, 301 со старых адресов.
Добавить:

```apache
# HTTPS и один хост (после выбора домена; заменить example.by)
RewriteEngine On
RewriteCond %{HTTPS} off [OR]
RewriteCond %{HTTP_HOST} ^www\. [NC]
RewriteRule ^ https://example.by%{REQUEST_URI} [L,R=301]

# Кеш картинок и шрифтов (файлы меняются редко, при замене — новое имя)
<IfModule mod_headers.c>
  <If "%{REQUEST_URI} =~ m#^/(images|clinic|stickers|cases|video)/# || %{REQUEST_URI} =~ m#\.(webp|jpg|png|svg|woff2)$#">
    Header set Cache-Control "public, max-age=2592000"

  Header always set X-Content-Type-Options "nosniff"
  Header always set Referrer-Policy "strict-origin-when-cross-origin"
  Header always set X-Frame-Options "SAMEORIGIN"
  Header always set Permissions-Policy "camera=(), microphone=(), geolocation=()"
  # HSTS — только когда HTTPS точно работает

</IfModule>
<IfModule mod_brotli.c>

</IfModule>
```
