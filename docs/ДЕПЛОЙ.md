# Деплой на hoste.by (статика, без Node.js)

Сайт собирается в набор готовых HTML-файлов (`output: 'export'` в
`next.config.mjs`) и лежит на обычном PHP-хостинге. Node.js на сервере не
нужен: он требуется только на компьютере разработчика во время сборки.
Единственный серверный код — `api/booking.php`, который принимает форму
записи и пересылает её в Telegram (см. `docs/ФОРМА-ЗАПИСИ.md`).

## Собрать

```bash
pnpm install          # один раз или после обновления зависимостей
pnpm optimize-images  # если добавляли новые фото (см. ГДЕ-ЧТО-МЕНЯТЬ.md)
pnpm build            # результат — папка out/
```

`out/` содержит все страницы трёх городов, соседних городов, блог,
`sitemap.xml`, `robots.txt`, `404.html`, `.htaccess` и `api/booking.php`.

## Выложить

1. Подключитесь к хостингу по SFTP/FTP (данные — в панели hoste.by).
2. Откройте корневую папку сайта (обычно `public_html/` или `www/<домен>/`).
3. Залейте **содержимое** папки `out/` (не саму папку) в корень, с заменой.
   Скрытый файл `.htaccess` тоже должен уехать — в FTP-клиенте включите показ
   скрытых файлов.
4. `api/config.php` с токеном бота лежит **только на сервере** (в репозитории
   его нет, он в `.gitignore`). При первом деплое создайте его по образцу
   `api/config.example.php`; при последующих — не затирайте.

Старые файлы `_next/static/<хэш>/…` от прошлых сборок можно удалять — имена
хэшированы, на новую сборку они не влияют, просто занимают место.

## Проверить после заливки

- Главная, `/minsk/`, `/rogachev/uslugi/implantaciya/` открываются, стили есть.
- Несуществующий адрес (`/abc/`) показывает фирменную 404, а не страницу Apache.
- `/sitemap.xml` и `/robots.txt` отдаются.
- Форма записи в Минске отправляет тестовую заявку и она приходит в Telegram.

## Локальная проверка статики

```bash
pnpm build
php -S localhost:8080 -t out
```

`php -S` отдаёт и HTML, и `api/booking.php` — можно прогнать форму целиком.
(`.htaccess` встроенный сервер PHP не читает, поэтому 404 локально будет
«голая» — это нормально.)

## Перенос на боевой домен

`lib/site-config.ts` → `siteUrl` (используется в sitemap, canonical и
Open Graph). После смены — пересобрать и перезалить.
