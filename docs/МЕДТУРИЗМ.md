# Страница медтуризма — /minsk/medturizm/

Посадочная для пациентов из России: имплантация и протезирование в Минске.
Главное действие — прислать снимок с сайта, менеджер связывается и называет
примерную стоимость.

Статус: **черновик** (13.10.2026). `MEDTOURISM_DRAFT = true` в
`content/medtourism.ts`: страница закрыта от индексации, её нет в sitemap и в
меню, пункты без подтверждения помечены плашкой «согласовать». Показываем
клиенту по прямой ссылке.

## Обсудить с клиентом на созвоне

Всё ниже уже стоит на странице как допущение — клиент смотрит и правит.

- [ ] **Трансфер и проживание** — что реально организуете (блок «Проживание и трансфер»)
- [ ] **Гарантия после отъезда** — онлайн-контроль по фото и бесплатное исправление при приезде: согласны? Компенсация дороги?
- [ ] **Сроки поездок** — 2–4 дня на импланты, 5–7 на коронки, 3–5 на All-on-4: так?
- [ ] **Кто смотрит снимки и как быстро отвечает** (сейчас «в течение рабочего дня»)
- [ ] **Оплата для россиян** — карты «Мир», наличные, только BYN? (в FAQ — «уточнит менеджер»)
- [ ] Цены: рубли — пересчёт BYN по курсу НБРБ, округление до 100 ₽. Устраивает или нужны свои цены в рублях?
- [ ] Заявки с пометкой `#медтуризм` — в ту же группу Telegram или в отдельную?
- [ ] Фото для hero (сейчас ресепшн Минска)

Перед публикацией проверить по официальным источникам блок «Как добраться»
(время в пути, документы для въезда).

## Публикация

1. Закрыть пункты выше, убрать ненужные `tbd: true` в `content/medtourism.ts`.
2. Поставить `MEDTOURISM_DRAFT = false` — страница откроется для поисковиков и попадёт в sitemap.
3. Добавить ссылки на страницу: главная Минска (карточка «Помощь с трансфером»), меню/подвал — по решению клиента.

## Сервер: обязательно до показа формы

Форма отправляет файлы — без настроек ниже снимки больше 1 МБ отваливаются
с ошибкой 413.

1. Обновить nginx по `docs/nginx-32dent.by.conf` → `location = /api/booking.php`:
   `client_max_body_size 30m`, `fastcgi_param PHP_VALUE …`, `fastcgi_read_timeout 180s`.
   Затем `sudo nginx -t && sudo systemctl reload nginx`.
2. Выложить новые `api/booking.php` и `api/booking-transport.php` (идут в сборке `out/api/`).
3. Проверить, что в PHP включено расширение `fileinfo` (`php -m | grep fileinfo`) — им проверяется тип файла.
4. Отправить тестовую заявку со снимком — в Telegram придёт заявка и ответом на неё файл.

Снимки на сервере не хранятся: PHP держит их во временной папке на время
запроса и пересылает в Telegram документами (без пережатия).

Юридически: снимки — сведения о здоровье. Чекбокс согласия это упоминает,
но передачу снимков через Telegram юрист клиники должен отразить в
политике и условиях согласия.
