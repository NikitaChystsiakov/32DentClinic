# Форма записи → Telegram

Все формы сайта (модалка «Записаться», калькулятор) отправляют заявку
POST-запросом в `/api/booking.php` (исходник — `public/api/booking.php`,
в сборке попадает в `out/api/booking.php`). Скрипт проверяет имя и
телефон, отсекает ботов (скрытое поле-ловушка, не больше 5 заявок с одного
IP за 10 минут) и присылает сообщение в Telegram:

```
🦷 Новая запись — Минск
Имя: Анна
Телефон: +375 (29) 123-45-67
Услуга: Имплантация
Комментарий: …
Откуда: форма записи, /minsk/uslugi/implantaciya/
Время: 13.09.2026 14:32
```

Минск и Жлобин принимают заявки через форму. Рогачёв — только по телефону:
администраторы не обрабатывали заявки с сайта, и заказчик попросил закрыть
форму. За это отвечает `hasBookingForm: false` в `config/cities.ts`: кнопки
«Записаться» этого города становятся ссылкой «Позвонить», а сам город
пропадает из выбора в форме. Чтобы снова включить — поставить `true`.

## Настройка получателя (5 шагов)

1. В Telegram откройте **@BotFather** → `/newbot`, задайте имя и username
   бота. В ответ придёт **токен** вида `123456789:AAH…` — это `bot_token`.
2. Откройте **@userinfobot** (или @getmyid_bot) — он покажет ваш числовой
   **Id**. Это `chat_id`. Для группового чата: добавьте бота в группу и
   возьмите id группы (отрицательное число) тем же способом или из ответа
   `https://api.telegram.org/bot<токен>/getUpdates`.
3. Напишите своему боту любое сообщение (`/start`) — иначе он не сможет
   писать вам первым.
4. На хостинге в папке `api/` скопируйте `config.example.php` в `config.php`
   и вставьте `bot_token` и `chat_id`.
5. Отправьте тестовую заявку с сайта — сообщение должно прийти в течение
   секунды.

**Переключить заявки на клиента** — заменить `chat_id` в `config.php` на id
клиента (или общего чата). Бот и сайт менять не нужно.

`config.php` не хранится в репозитории (`.gitignore`) и закрыт от прямого
скачивания через `api/.htaccess`.

## Коды ошибок скрипта

Ответ — JSON `{ ok: false, error: '…' }`:

| error | что значит |
|---|---|
| `not_configured` | нет `config.php` или пустой токен/chat_id |
| `name_required`, `phone_invalid` | не прошла валидация (телефон — `+375` и 9 цифр) |
| `rate_limited` | больше 5 заявок с одного IP за 10 минут |
| `telegram_failed` | Telegram не принял сообщение — проверить токен, chat_id и что боту писали `/start` |

При любой ошибке форма на сайте показывает «позвоните по телефону …» с
номером клиники текущего города.

## Локальная проверка

```bash
pnpm build
cp public/api/config.example.php out/api/config.php   # вписать токен и chat_id
php -S localhost:8080 -t out
```

Открыть http://localhost:8080/minsk/ → «Записаться» → отправить. Или из
терминала:

```bash
curl -s -X POST localhost:8080/api/booking.php \
  -H 'Content-Type: application/json' \
  -d '{"name":"Тест","phone":"+375 (29) 123-45-67","city":"minsk","service":"Имплантация"}'
```
