# Форма записи → бот клиники

Все формы сайта (модалка «Записаться», калькулятор) отправляют заявку
POST-запросом в `/api/booking.php` (исходник — `public/api/booking.php`,
в сборке попадает в `out/api/booking.php`). Скрипт проверяет имя и
телефон, отсекает ботов (скрытое поле-ловушка, не больше 5 заявок с одного
IP за 10 минут) и передаёт текст в `booking-transport.php`, который
отправляет его туда, куда указано в `config.php` (`transport`):

| transport | куда уходит заявка |
|---|---|
| `telegram` | Telegram-бот пишет в группу (токен бота + id группы) |
| `webhook` | POST JSON `{ city, text }` на HTTPS-адрес бота/CRM клиники с заголовком `Authorization: Bearer <webhook_token>` — заготовка, сверить с их API |
| `stub` | заглушка: никуда не отправляет, в лог пишет только город. **Только для проверки** — посетитель видит «отправлено», заявка теряется |

Заявки всех трёх городов могут идти в одну группу. Город — во второй строке
и хэштегом в конце, по нему администратор фильтрует свои заявки:

```
🦷 Новая заявка с сайта
📍 Город: Минск

Имя: Анна
Телефон: +375 (29) 123-45-67
Услуга: Имплантация
Комментарий: …
Откуда: форма записи, /minsk/uslugi/implantaciya/
Время: 13.09.2026 14:32

#минск
```

Город берётся только из белого списка (`CITIES` в `booking.php`), иначе —
«город не указан» / `#без_города`. Если позже каждому городу понадобится
свой чат или своя тема в группе — `chat_ids` / `topic_ids` в `config.php`,
код менять не нужно.

**Пока нет токена бота клиники:** на тестовом сервере можно поставить
`'transport' => 'stub'`, чтобы проверить форму. Как только пришлют токен —
`'transport' => 'telegram'`, вписать `bot_token` и `chat_id` группы.
Если их бот окажется не Telegram — `'transport' => 'webhook'` и поправить
формат запроса в функции `sendWebhook` (`public/api/booking-transport.php`).

## Безопасность

- Токены — только в `config.php` на сервере, в репозиторий не попадают
  (`.gitignore`). Лучшее место — на уровень выше папки сайта:
  `~/dent32-booking-config.php` — веб-сервер его не отдаёт вообще. Второй
  вариант — `public_html/api/config.php`, закрыт `api/.htaccess`.
- `booking-transport.php` напрямую по URL не открывается (404 и `.htaccess`).
- Запросы с чужих сайтов (другой Origin) отклоняются, лимит — 5 заявок с IP
  за 10 минут, TLS-сертификат получателя проверяется, `webhook` — только https.
- Имя и телефон пациента в логи сервера не пишутся.

Минск и Жлобин принимают заявки через форму. Рогачёв — только по телефону:
администраторы не обрабатывали заявки с сайта, и заказчик попросил закрыть
форму. За это отвечает `hasBookingForm: false` в `config/cities.ts`: кнопки
«Записаться» этого города становятся ссылкой «Позвонить», а сам город
пропадает из выбора в форме. Чтобы снова включить — поставить `true`.

## Настройка получателя (5 шагов)

1. В Telegram откройте **@BotFather** → `/newbot`, задайте имя и username
   бота. В ответ придёт **токен** вида `123456789:AAH…` — это `bot_token`.
2. Откройте **@userinfobot** (или @getmyid_bot) — он покажет ваш числовой
   **Id**. Это `chat_id`. Для группового чата: добавьте бота в группу и
   возьмите id группы (отрицательное число) тем же способом или из ответа
   `https://api.telegram.org/bot<токен>/getUpdates`.
3. Напишите своему боту любое сообщение (`/start`) — иначе он не сможет
   писать вам первым.
4. Скопируйте `config.example.php` в `~/dent32-booking-config.php` (на уровень
   выше папки сайта) или в `api/config.php` и вставьте `bot_token` и `chat_id`.
5. Отправьте тестовую заявку с сайта — сообщение должно прийти в течение
   секунды.

**Переключить заявки на бота клиники** — заменить `bot_token` и `chat_id` в
`config.php` на их значения. Сайт менять не нужно.

`config.php` не хранится в репозитории (`.gitignore`) и закрыт от прямого
скачивания через `api/.htaccess`.

## Коды ошибок скрипта

Ответ — JSON `{ ok: false, error: '…' }`:

| error | что значит |
|---|---|
| `not_configured` | нет `config.php`, пустой токен/chat_id или неизвестный `transport` |
| `name_required`, `phone_invalid` | не прошла валидация (телефон — `+375` и 9 цифр) |
| `rate_limited` | больше 5 заявок с одного IP за 10 минут |
| `delivery_failed` | получатель не принял сообщение — проверить токен, chat_id, что бот добавлен в группу (или ему писали `/start`), для `webhook` — адрес и токен |

При любой ошибке форма на сайте показывает «позвоните по телефону …» с
номером клиники текущего города.

## Локальная проверка

```bash
pnpm build
cp public/api/config.example.php out/api/config.php   # вписать токен и chat_id
php -S localhost:8080 -t out
```

Открыть http://localhost:8080/minsk/ → «Записаться» → отправить. Или из
терминала:

```bash
curl -s -X POST localhost:8080/api/booking.php \
  -H 'Content-Type: application/json' \
  -d '{"name":"Тест","phone":"+375 (29) 123-45-67","city":"minsk","service":"Имплантация"}'
```
